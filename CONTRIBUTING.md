# Contributing to Technoksha Repository

We appreciate your interest in contributing! Follow these guidelines to ensure a smooth collaboration process.

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone** your fork locally.
3. Create a **feature branch**:
   ```bash
   git checkout -b <feature-or-fix-name>
   ```
4. Make your changes, ensuring you follow the existing style (Markdown format, line endings, etc.).
5. **Commit** your work with a clear message:
   ```bash
   git commit -m "Short description of changes"
   ```
6. **Push** to your fork:
   ```bash
   git push origin <feature-or-fix-name>
   ```
7. Open a **Pull Request** against the `main` branch of the upstream repository.

## Code of Conduct
All contributors must adhere to the [Code of Conduct](CODE_OF_CONDUCT.md). Violations may result in removal from the project.

## Review Process
- PRs will be reviewed by maintainers within a few days.
- Ensure that your PR includes a brief description of the changes and any relevant screenshots or testing steps.
- Resolve any feedback before merging.

## Issues
- Open an issue before starting work on a substantial feature or fix.
- Include a clear title, description, steps to reproduce (if applicable), and any relevant tags.

## Style Guidelines
- Use **GitHub Flavored Markdown** for documentation.
- Keep line lengths reasonable (≤ 120 characters).
- Prefer **LF** line endings for cross‑platform compatibility.
